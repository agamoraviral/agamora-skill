# agamora-video — ролик для руководства

Брат навыка `agamora-presentations`: тот же фирменный стиль, шрифт IBM Plex Sans и бренды
(`../agamora-presentations/assets`, `brands`, `brands-local`), на выходе — MP4 со звуком.
Почему каждое правило существует — `references/lessons.md`.

## Порядок работы

0. **Айдентика — обязательный вопрос, даже если о ней не сказали:** чей бренд, брендбук или шаблон, логотип,
   цвета, шрифты, образцы презентаций. Ролик затачивается под бренд заказчика (`brands-local/<имя>/` навыка
   презентаций, `meta.brand` сценария: логотип и цвета по ролям палитры берутся из `brand.json`), а не штампуется
   по примеру. Нет бренда — сказать, что будет нейтральный стиль.
1. **Сценарий.** Сцены: обложка → тизер с тремя главными цифрами → заставка → главы → итог с призывом.
   Факты — только из согласованных материалов (презентация, калькулятор), ничего не выдумывать.
2. **Текст диктора** — по правилам ниже; согласовать с заказчиком до синтеза. Неизвестные расшифровки — спросить.
3. **Голос.** `voice_tools.js bench "фрагмент"` — образцы и оценка; склейку образцов дать человеку послушать.
4. **Сцены.** Скопировать `scripts/scenario.example.js` к материалам, написать функции сцен на приёмах движка,
   появление элементов привязать к словам диктора: `Q("слово")`.
5. **Картинка без синтеза:** `--silent --preview папка` → листы кадров смотреть глазами, автопроверка вёрстки.
6. **Озвучка** (`--preview` уже с синтезом) → `voice_tools.js judge папка/audio` → каждый фрагмент не ниже 9 из 10;
   ошибки исправлять переписыванием фразы, а не надеждой на повторный синтез.
7. **Рендер** и проверка: 1920×1080, 30 кадров/с, есть звук, длительность, первый кадр — обложка, около −16 LUFS.
8. **Выдача:** файл человеку (рабочий стол, чат); перед отправкой в мессенджер проверить превью.

## Жёсткие правила

**Стиль**
- Чужая айдентика в материалах навыка запрещена — логотипы, названия и фирменный стиль сторонних компаний
  в примерах, скриншотах и демонстрациях нарушают авторские права. Для них — бренд навыка `agamora`.
- Только светлая тема в стиле презентаций: белый фон, тёмно-синий / синий / светло-синий, плоские карточки,
  метки капсом, тонкие линейки, иконки deckkit, IBM Plex Sans, логотип бренда в углу. Тёмную тему не предлагать.
- Без технодекора и «ИИ-слопа»: свечений, неоновых орбит, сеток, тёмных фонов, мультяшных роботов. Агент — иконка бота.
- Ролик — ожившая презентация: сцена собирается из элементов слайдов, движение показывает смысл
  (передачи между людьми, перестройку команды, нарастание эффекта), а не украшает.
- Первый кадр — обложка: титульный слайд с логотипом, названием и тремя главными цифрами. Это превью в Telegram;
  проявление из белого в начале даёт пустое превью.

**Текст диктора**
- Не повторяет слайд дословно: доносит мысль, подробности — на экране. Ключевые цифры звучат вслух в момент появления.
- Без аббревиатур — только расшифровки (неизвестные — спросить); числа словами; живой деловой язык, короткие фразы.
- Для синтеза: без риторических вопросов и смысловых тире (синтез отыгрывает их плохо), перечисление после
  двоеточия — короткими предложениями. Если синтез искажает числительное, дать его цифрами.
- Субтитры (`sub`) и текст для синтеза (`say`) — с одинаковым числом предложений; словарь заказчика соблюдать.

**Голос**
- OpenRouter `/api/v1/audio/speech`. По умолчанию `elevenlabs/eleven-v4` · `jessica` — лучший по русскому
  произношению из 13 сравнённых женских голосов; запасной — `minimax/speech-2.8-hd` · `Russian_AmbitiousWoman`.
- Голоса реальных людей без их письменного согласия не клонируем — в том числе дикторов по демозаписям студий.
- Ключ — только из `~/secrets/openrouter.key`, не печатать и не прикладывать файл ключа в чат.
  Для запросов со звуком на балансе OpenRouter нужно не меньше $0,50.

**Звук и рендер**
- Голос — −16 LUFS; музыка под речью −11 дБ и в паузах ниже голоса; удары — на «посадку» цифр (`land`).
- Сведение — отдельным проходом в файл ровно на длительность ролика; не `-shortest` с фильтрами при кодировании.
- Кадр — чистая функция времени `renderAt(t)`; JPEG-кадры уходят в ffmpeg потоком; при закрытии ffmpeg не ждать `drain`.

## Команды

```bash
cd skills/agamora-video/scripts && npm install          # один раз: puppeteer-core и ffmpeg-static (Chrome — системный)
node render_video.js --scenario путь/сценарий.js --silent --preview папка   # картинка без синтеза
node render_video.js --scenario путь/сценарий.js --preview папка            # с синтезом и проверкой привязки к речи
node voice_tools.js judge путь/audio                                          # прослушать готовые фрагменты
node render_video.js --scenario путь/сценарий.js                              # ролик (meta.output или --out)
node render_video.js --scenario путь/сценарий.js --remux                      # заменить только звук
```

## Файлы

| Файл | Что внутри |
|---|---|
| `scripts/render_video.js` | движок: синтез и кэш речи, разметка по паузам, приёмы анимации, шторки, субтитры, проверка, сборка |
| `scripts/scenario.example.js` | пример сценария — ролик, в котором навыки представляют себя сами: обложка, заставка, проблема, презентации, ролик, бренд, результат, итог (бренд `agamora`) |
| `scripts/music.js` | музыкальная подложка и акценты по таймлайну, приглушение под речью |
| `scripts/voice_tools.js` | подбор голоса (`bench`) и прослушивание готовой озвучки (`judge`) моделью-оценщиком |
| `references/lessons.md` | уроки: что не сработало и почему правила такие |
