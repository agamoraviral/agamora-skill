# Бренд: палитра, логотип, мотив

Без бренда дек собирается в нейтральной палитре по умолчанию (тёмно-синий, синий, светло-синий, голубой
мотива) и без логотипа. Фирменный стиль подключается файлом `brand.json`.

## Где лежат бренды

- `brands/<имя>/` — открытые бренды внутри скилла (пример — `brands/example/`);
- `brands-local/<имя>/` — **локальные бренды, не попадают в git** (логотипы и цвета конкретной компании);
- любой путь к папке с `brand.json`.

Какой бренд взять: параметр `build(..., brand="<имя или путь>")`, иначе переменная окружения
`DECK_BRAND`, иначе нейтральная палитра.

## Формат `brand.json`

```json
{
  "name": "Компания",
  "logo": "logo.png",
  "logo_white": "logo_white.png",
  "colors": {
    "primary": "#123A6B",
    "accent":  "#1F6FD1",
    "light":   "#9DB8E3",
    "motif":   "#29A3E0",
    "#E3F2FB": "#E6F0FA"
  }
}
```

- `fonts` — `{"text": "...", "display": "..."}`: шрифт текста и шрифт заголовков и крупных чисел из
  встроенных (IBM Plex Sans, Onest, Unbounded); по умолчанию оба — IBM Plex Sans;
- `css` — дополнительные правила поверх базовых (фон слайда, кегль заголовка и т. п.);
- `logo` — для светлого фона (вверху справа на каждом слайде, 30 px; на обложке — 40 px);
- `logo_white` — для тёмных плоскостей; если его нет, берётся `logo` с белым фильтром;
- `colors` — замены цветов: ключ — роль палитры или исходный цвет «#RRGGBB», значение — цвет бренда.

Роли палитры (исходные значения — `deckkit/tokens.py`):

| Роль | Исходный | Где используется |
|---|---|---|
| `primary` | `#002D72` | заголовки, главные плоскости, выделенный столбец |
| `accent` | `#0070BA` | метка раздела, агенты, рукописные пометки |
| `light` | `#8CB8E0` | обычные столбцы, вторичные полосы |
| `motif` | `#009FDF` | наклонные полосы мотива, номера на тёмном |
| `ink` / `body` / `muted` | `#1A2433` / `#3B4758` / `#5F6B7C` | три тона текста |
| `rule` / `pale` | `#D5DCE5` / `#F2F5F9` | линии, светлые зоны |
| `risk` | `#B42318` | только риск и затраты |
| `on_navy_text`, `tobe_zone`, `asis_zone`, … | см. `EXTRA` в `tokens.py` | служебные оттенки схем |

После смены палитры обязательно прогнать `qa.py`: проверка контраста покажет, где новый цвет не читается.
Иллюстрации обложек (`bank_swarm`, `swarm_to_bank`) рисуют грани оттенками основного цвета, заданными
отдельно: при сильной смене палитры добавьте их в `colors` или проверьте обложку глазами.

## Готовые профили

- без бренда — нейтральная палитра (тёмно-синий, синий, голубой мотив), IBM Plex Sans, белый фон;
- `brands/example` — пример замены палитры («графит и кобальт»);
- `brands/editorial` — в духе деков режима Design: тёплый фон `#F3F0E8`, заголовки Unbounded, текст
  Onest, почти чёрные плоскости и один горячий оранжевый акцент.

## Мотив бренда

Фирменная графика важнее иллюстраций: крупные плоскости основного цвета и повторяющийся элемент бренда
(в палитре по умолчанию — наклонные полосы `slant_bars`, `pgram`, ступени `year_steps`). Мотив — на
обложке и не больше чем на двух-трёх слайдах; он структурный (стоит на сетке, уходит в обрез), а не
наклейка в углу.
